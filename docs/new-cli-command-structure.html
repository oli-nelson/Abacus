Abacus CLI: Current → Proposal

Bare commands select operations. Positional arguments identify their subjects. --options configure or modify them.

Clean break: no compatibility support for replaced spellings or implicit run syntax. The explicitly retained short options remain supported.

Parsing and behavior

  • Bare abacus prints help; orchestration requires run.
  • Accept --repo before or after repository-scoped commands.
  • Reject options outside their command’s scope.
  • Support -- as the end-of-options marker; parse message and prompt values contextually.
  • health diagnoses the repository; preflight validates a specific run configuration without starting agents.
  • new retains the multi-agent layout and requires --agents <count>; init configures an existing Git/Beads repository.
  • branches prune retains its scope: local Abacus branches for closed tickets, skipping checked-out branches.
